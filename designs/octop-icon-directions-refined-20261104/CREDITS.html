第二轮图标 · 来源与许可

本预览将以下开源图标编排为三个可比较的 Octop 方案。保留原始图标轮廓；调整展示尺寸、主题与交互状态。SVG 数据随预览本地提供，无需远程接口。

A · 圆弧细线

Solar Linear，作者 480 Design。依据 CC BY 4.0 使用，保留署名。原始来源，SVG 数据。本预览未修改图形，仅选择子集、设置展示尺寸与 currentColor。

B · 墨色双层

Phosphor Icons Duotone，作者 Phosphor Icons。MIT 许可与版权声明。

C · 柔光彩塑

Fluent UI System Color Icons，作者 Microsoft Corporation。MIT 许可与版权声明。

图标映射及来源记录：icon-sources.json。动态表情头像沿用 Octop 当前自定义头像。
