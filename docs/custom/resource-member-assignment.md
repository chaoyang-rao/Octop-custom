# 专家与技能包分配

企业授权中心的“企业专家”和“企业技能包”中，每张资源卡片提供“分配人员”。可选择所有成员，或从已通过公司飞书登录的成员名单中按姓名多选。指定模式至少选择一人。

已发布资源点击“保存分配”后更新分发范围，客户端按权限自动同步；此操作保留已发布内容和其他草稿。新建但尚未发布的资源只保存草稿分配，仍需正常发布。目录版本发生变化时，旧表单会被拒绝，人员选择保留供核对。

专家引用的技能包应覆盖同一人员范围。功能权限和“MCP开放权限”继续独立检查；给某人分配专家不会额外开放 MCP。取消分发保留成员原有本地副本、聊天和个人资料。

接口：PUT `/api/enterprise/resources/admin/assignment`，请求包含 `resource_id`、`expected_etag` 与 `audience: {scope: "all" | "selected", subjects: [...]}`。全部模式使用空数组，指定模式至少一个成员。只有企业网页管理员可修改，设备授权不能写入。
