# 同事首次登录 Octop

企业定制版 `1.0.3b3.post2026111703` 起，安装包已预设公司登录地址。

1. 打开 Octop，点击“使用公司飞书登录”。浏览器会打开公司登录页。
2. 点击“使用公司飞书继续”，按飞书页面提示完成登录。无需注册 Octop 账号或填写模型密钥。
3. 在“确认登录这台电脑”页核对飞书姓名与设备，点击“确认本次登录”。只确认自己刚刚发起的登录。
4. 回到 Octop。页面会显示模型同步、小通启动和进入会话的进度，准备完成后自动进入聊天。

若浏览器没有自动打开，在 Octop 点击“重新打开公司登录页”。登录码会自动带入；只有自动带入失败时才需要展开登录码并手动填写。登录码过期后返回 Octop 重新发起。

如果模型或小通准备失败，页面会显示原因与“重试”。重试仍失败时，联系超级管理员检查企业模型服务和账号权限，无需同事自行创建供应商或复制 API Key。

MCP 与桌宠仍由超级管理员按成员名单开放。登录成功不会自动授予三个 MCP 或桌宠权限；未开放时联系管理员，说明需要哪一项。详见[企业成员开放权限与独立桌宠](central-member-access.md)。

已有本机账号和聊天记录的用户，可展开“已有本机账号和聊天记录？”走原账号校验与绑定流程。系统仍要求核对企业身份与本机账号后明确确认，避免把数据绑到错误账号。

管理员账号密码、其他登录方式和设备管理保留在折叠入口中。旧安装包可继续用手动登录码；新引导需要更新主程序，只有更新网页授权中心不会改变旧客户端界面。
