# 112806 / 哆啦 0.10.9

本次客户端与桌宠同批构建，仍分别下载和安装，沿用原账号、聊天、配置和更新权限。

- 浅色聊天界面使用黑色发送按钮和白色箭头，禁用时降低箭头亮度；保留完整键盘焦点。
- 桌面聊天主面板上下贴边、边缘平直，仅左上、左下保留 20px 弧度；模型选择位于右侧发送按钮前并向内收 12px，保留模型、思考设置和草稿。
- 修复团队复用 WebSocket 后的多轮回答收尾：完成后恢复发送状态，成员仍在输出时保留其内容与监听。
- 团队派工、依赖回报与改派使用有界交接包；成员上下文按项目与任务线区分，原文和检查点继续可查。
- 保留 112805 已发布的头像动效范围和 112804 的导航滚动调整。

Windows、Intel Mac、Apple 芯片 Mac 客户端与 Mac/Windows 桌宠通过现有定制发布流水线校验后进入同一发行版。企业中心的成员通知范围仍由管理员单独发布。

本地界面验证：浅色发送按钮 `rgb(0,0,0)`、白色箭头；左侧圆角 `20px`、右侧 `0px`；模型控件位于发送按钮左侧，切换模型后输入草稿保持。聊天相关测试 696 项及模型控件源码检查 9 项通过，TypeScript 检查和生产构建通过。
