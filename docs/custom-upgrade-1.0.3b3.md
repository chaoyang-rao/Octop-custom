# 定制版升级至 1.0.3b3

本次合并官方 `v1.0.3b3`（`4811eb45996169e86006db1b6451264ff4758223`），定制运行版本为 `1.0.3b3.post20261106`。

## 定制更新入口

- 更新页分别显示当前定制版本与官方参考版本，并提供定制仓库链接。
- 官方有新版本时，不再把它显示为定制版可直接安装的更新。
- 定制版调用官方就地升级接口会在下载、探测和创建升级任务之前返回 `UPDATE_CUSTOM_BUILD_PROTECTED`（HTTP 409）。
- 官方版保留原更新流程；定制版仍需合并审核上游后构建安装包。

## 兼容处理

- 保留动态头像、Solar Arc 图标、小通主专家、成员群聊回复、任务群、CLI 复用、上下文隔离及项目范围内的跨会话记忆。
- 适配上游控制数据库中的头像存储。替换、清除账号图片时保留私有历史副本；缓存版本包含内容哈希。
- 上游移除内置专家目录后，新用户的小通可使用本地 `default` 模板初始化。
- 保存独立的 `upstream-1.0.3b3` 程序基线；原始基线保留。冻结的后端、前端和运行库按清单组合构建。
- 发布标签校验改为读取锁定的上游版本。工作分支默认使用 `custom-*` 预览标签；生产 `v*` 标签要求位于 `main`。
