哆啦 Windows 版

支持 Windows 10 / 11 64 位。双击安装，打开哆啦后点“企业登录”，使用飞书登录。
由超级管理员开放的模型、专家、MCP 和桌宠权限自动同步。专家已绑定 MCP，无需重复勾选。
首次登录且获得桌宠权限后会显示内置 KuroCat 小黑猫，无需下载内部角色图包。未获开放时请联系企业管理员。

双击哆啦打开聊天；Ctrl+Alt+空格显示或隐藏聊天。
关闭聊天窗口只隐藏聊天，托盘菜单中选择“退出哆啦”才会退出。
拖动小黑猫可移动和提起，停在放下的位置，不自动吸附或收进屏幕边缘。
鼠标移动时视线和爪子跟随；敲键盘、点击鼠标、摸头、打瞌睡和多键彩蛋由原生动作引擎驱动。
托盘右键可调整大小、暂停动作、开关小黑猫彩蛋、朗读和打开资源与模型。
键鼠事件只在本机用于动画；不写入聊天、业务日志或模型请求。隐藏小猫或退出账号时停止动作进程。
聊天顶部选择专家或团队；设置中管理知识库、团队，小通仍为团队主持人。
支持新对话、附件、图片、复制、打断、补充要求与需要确认的工具操作。
麦克风需 Windows 中安装中文语音识别语言包，并允许桌面应用使用麦克风。

数据存放在 %LOCALAPPDATA%\OctopCompanion\Data，与主 Octop 独立。
升级、卸载不会删除聊天数据。运行日志位于 %LOCALAPPDATA%\OctopCompanion\Logs。
卸载请使用 Windows 设置“应用”中的哆啦卸载入口。
