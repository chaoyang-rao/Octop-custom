哆啦使用说明

在顶部“哆啦”旁快捷选择专家或团队。其余功能集中在右上角“功能与设置”。

对话控制与附件

  • 回答过程中可继续输入：“补充本轮”调整当前任务，“排队发送”留到当前任务结束后执行。待发消息可撤回；停止或断线后保留待发内容，点击“继续发送”再执行。
  • “停止回答”会发送当前会话的取消请求并停止朗读；已有回答保留。需要确认操作或补充答案时，在聊天卡片中确认这一次、拒绝或提交答案。
  • 消息下方的“…”可重新回答、再次发送或编辑后再发。编辑重发会新增消息，保留原有对话。
  • 附件支持 PNG、JPG、WebP、GIF、Excel（xls/xlsx）、CSV 和 PDF，每次最多四个、每个不超过 12 MB。可以选择、拖入或粘贴。
  • 关闭或重开客户端后，待发消息保留但不自动执行；重新登录其他账号不会继承上一账号的草稿和待发内容。

专家与 MCP

哆啦直接使用所选专家已保存的 MCP，每次发送前自动核对当前绑定与本人权限，无需在桌宠里再次勾选连接器。更换专家不会把上一个专家的 MCP 带到下一位；未绑定 MCP 的通用专家仍可正常聊天。

  1. 点击顶部专家名称，选择本人可用的专家，直接提问。
  2. 各专家保留自己的草稿与会话，切换回来继续；回答中、等待确认或有待发消息时先处理当前任务再切换。
  3. 售后、词元、负利润、知识库的原板块入口仍在设置中；知识库板块可额外选择本人已授权的知识库。

团队协作

  1. 打开“功能与设置 → 团队”，选择已有团队，或填写名称新建团队。
  2. 勾选本人可用的参与专家，点击“创建团队”或“保存成员”。小通固定为主持人，不能移除或替换。
  3. 关闭设置后直接提问。小通负责分工与汇总，各位专家以自己的名字独立回复，沿用各自模型、MCP、知识库和权限。

团队回答期间可补充本轮或保留下一条待发消息。待发消息需要点击“继续发送”，避免打断仍在回复的成员。“停止回答”停止当前主持回合，已开始的成员任务可能继续，与主程序一致。

切换团队会分别保留本机草稿与会话；有任务、待确认操作或待发消息时，先处理完成再切换或修改成员。新建专家后点击“刷新资源”即可添加。桌宠中的团队保存在自己的独立引擎内，不要求启动 Octop 主程序。

自己创建与接入

在统一入口点击“创建与管理专家”创建自己的专家、设置角色和技能；点击“接入与管理 MCP”添加 HTTP、HTTPS 或本机 stdio MCP，并在完整的专家管理页面把 MCP 配置给相应专家。完成后回到桌宠点击“刷新资源”，再从顶栏选择专家。stdio 服务需要本机已安装相应程序。

Octop 主程序依然可以自建专家、自由配置 MCP；哆啦只简化日常选择，不改变主程序的配置方式。

公司售后、词元和负利润 MCP 由超级管理员按成员开放。自建专家不会增加企业数据权限，也不能绕过公司授权；自己的 MCP 按其服务要求配置认证。桌宠使用独立数据目录，主程序中的本地专家不会自动复制进桌宠。

边缘收起

将桌宠拖到显示器的外侧边缘并松手，稍候会只露出头和手。鼠标靠近或点击时展开，移开后再收起。拖离边缘可恢复常驻显示；双击仍可打开或收起聊天。相邻显示器之间的连接边界不会触发收起。

“功能与设置”可关闭“边缘收起”或打开“宠物大小”。收起状态不会改变保存的实际尺寸。调整显示器布局后，桌宠会回到可见区域。

图片、语音与会话

可粘贴、拖入或选择图片；语音识别结果先进入输入框。Enter 发送，Shift+Enter 换行。“自动朗读”和“新对话”位于统一入口。切换板块保留各自草稿和会话，收起窗口不会中断回答。

账号与独立运行

使用公司飞书登录后按本人权限同步资源。关闭 Octop 主程序后，桌宠仍可运行。聊天及本机资源保存在 ~/Library/Application Support/OctopCompanion/Data，不与主程序的本地数据混写。

遇到权限错误时联系管理员确认开放范围；连接故障可刷新资源，或在桌宠菜单查看运行日志。
