# 回答质量固定样例

30 个虚构场景覆盖概念解释、方案建议、数据分析、澄清判断、多轮跟进和团队汇总。`max_chars` 是人工评审参考，不是生产截断规则。

比较时固定模型、生成参数、输入与资料，分别使用旧提示词和新提示词生成答案；保留原始回答、模型标识、耗时与 token 用量。分别评审切题、准确、完整、表达和篇幅，每项 0–2 分，优先检查数字、口径、权限和完成状态。不能只凭字数减少判断质量提升。

单轮、无工具的对照只能验证表达及给定证据的使用，不能代表真实工具调用、长会话记忆或生产业务准确率。完整验收还需使用实际聊天入口验证权限、工具返回、上下文快照及团队交付。
